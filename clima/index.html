Sistema meteorológico archivado

Clima

El módulo cruzaba pronósticos oficiales y modelos numéricos para presentar una lectura operativa por jornada, bloque horario y zona de rodaje. El objetivo era detectar lluvia, viento, frío y desacuerdos entre fuentes con suficiente anticipación.

La actualización automática fue detenida al finalizar el rodaje. Esta página ya no ofrece un pronóstico vigente y no debe utilizarse para tomar decisiones meteorológicas actuales.
Fuentes

INUMET y MetSul

Pronóstico oficial, advertencias y contexto meteorológico regional.

Modelos

ECMWF y GFS

Comparación de series horarias obtenidas mediante Open-Meteo.

Plan de rodaje

Cuatro jornadas

Ciudad de la Costa, La Paz, Las Piedras y Parque del Plata.

Automatización

GitHub Actions

Un flujo en Python regeneraba el archivo meteorológico y publicaba los cambios en GitHub Pages.
